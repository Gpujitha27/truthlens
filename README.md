# TruthLens

## AI-Powered Deepfake Detection Platform

TruthLens is a web-based landing page for an AI-powered deepfake detection platform designed to help users verify the authenticity of images, videos, and audio.

The current version of TruthLens is a **frontend HTML landing page** that presents the project's purpose, value proposition, key features, workflow, and demo call-to-action.

## Unique Value Proposition

> **Detects deepfakes in seconds with AI-powered authenticity reports anyone can understand.**

## Current Features

* Modern and responsive landing page
* Introduction to the TruthLens platform
* Image deepfake detection feature section
* Video deepfake detection feature section
* Audio deepfake detection feature section
* Simple three-step workflow:

  1. Upload
  2. Analyze
  3. Understand
* Call-to-action for requesting a demo
* Responsive design for desktop and mobile screens
* Clean AI and cybersecurity-inspired interface

## Current Project Status

At present, the project contains the **frontend landing page only**.

The actual AI deepfake detection system, backend services, database, authentication, file processing, and authenticity analysis are planned for future development.

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Basic HTML links and UI components

No external frameworks or backend technologies are currently required for the landing page.

## How to Run

Since this is currently a static HTML website, no server or installation is required.

### Option 1: Open Directly

1. Download or clone the project.
2. Open `truthlens.html` in any modern web browser.

### Option 2: Use VS Code

1. Open the TruthLens project folder in VS Code.
2. Open `truthlens.html`.
3. Use a browser or the Live Server extension to view the website.
